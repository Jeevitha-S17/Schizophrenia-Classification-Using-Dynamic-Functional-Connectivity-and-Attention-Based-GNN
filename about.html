📖 About This Project

Schizophrenia DFC Predictor

Dynamic Functional Connectivity analysis using Attention-Based Graph Neural Networks

🛠️

Technologies Used

🐍 Language & Environment

Python 3.9 — All code pinned to this version for compatibility

🧠 Deep Learning & Graph Modeling

  • PyTorch — Core neural network framework (tensors, autograd, optimizers)
  • PyTorch Geometric (PyG) — Graph neural network library:
    • GATv2Conv — Graph Attention Network layers (the "spatial attention" mechanism)
    • Batch, Data — Graph data structures for batching variable-sized graphs
    • global_mean_pool / global_max_pool — Pooling node features into graph-level embeddings
    • nn.TransformerEncoder — PyTorch built-in sequence/temporal attention mechanism across pseudo-windows

📉 Visualization

Methodology

Step 1 — Image-to-Signal Conversion

Each subject's connectivity-matrix PNG is resized to a fixed ROI×ROI grid. Since the image is a rendered heatmap rather than raw numbers, pixel colors are matched against a colormap lookup table (nearest-color search) to recover approximate correlation values in [-1, 1] — with a grayscale-intensity fallback if the image isn't clearly colormap-encoded.

Step 2 — Pseudo-Dynamic Window Generation
⚠️ Core Methodological Workaround

Since the dataset has no real time-series, "dynamic" connectivity is approximated: each subject's static matrix is perturbed N=15 times using reproducible edge-wise Gaussian bootstrap resampling — noise proportional to each edge's strength, symmetrized, clipped back into a valid range. This gives the model a sequence to reason over, standing in for genuine sliding-window analysis. This is explicitly flagged everywhere as an approximation, not measured brain activity.

Step 3 — Graph Construction

Every connectivity matrix (static, or each pseudo-window) becomes a graph: nodes = brain ROIs (feature = that ROI's full connectivity row), edges = top-10 strongest connections per node, edge weight = the connectivity value. This is the standard way to make a GNN applicable to connectivity data.

Step 4 — Attention-Based GNN Architecture

Two-level attention, matching the project brief:

  • Spatial attention (GATv2Conv): Learns which ROI-to-ROI connections matter within each window/graph
  • Sequence attention (Transformer encoder): Learns which of the N pseudo-windows carry the most discriminative signal, combining them into one subject-level representation
💡 Static Baseline

A static baseline model uses the identical spatial-attention block but skips the sequence-attention stage entirely — this isolates whether the windowed/temporal component actually helps, versus just being architectural complexity.

Step 5 — Training Methodology
  • Stratified train/validation split (class ratio preserved), test set fully held out
  • Class-weighted Cross-Entropy Loss — Handles class imbalance
  • AdamW optimizer + ReduceLROnPlateau scheduler + early stopping on validation F1
  • Best-checkpoint selection (not last-epoch) based on validation F1
Step 6 — Explainability Methodology

Rather than treating the GNN as a black box, we extract the model's actual internal attention weights:

  • GAT edge-attention weights aggregated per node → identifies which brain regions the model focused on
  • Transformer self-attention weights, manually replayed since PyTorch doesn't expose them by default → identifies which pseudo-window the model relied on most
Step 7 — Comparative Evaluation Methodology
📊 Key Approach

Every stage (training, testing, single-image prediction) reports the static and pseudo-dynamic models side by side, directly addressing the project's stated goal of comparing dynamic vs static connectivity methods, rather than reporting the dynamic model in isolation.

Model Architecture Overview

Dynamic Model

  • Input: N=15 pseudo-window graphs
  • Spatial Encoder: GATv2Conv (2 layers)
  • Sequence Encoder: Transformer (self-attention)
  • Output: Subject-level classification

Static Model

  • Input: Single static graph
  • Spatial Encoder: GATv2Conv (2 layers)
  • Sequence Encoder: (skipped)
  • Output: Subject-level classification
Both models use the same spatial attention backbone and classifier head
